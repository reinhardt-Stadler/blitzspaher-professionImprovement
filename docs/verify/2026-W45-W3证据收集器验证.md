## 1. 设计：与 ObservationStore 的分工

避免重复造轮子——两者的职责不同：

| 组件 | 时机 | 职责 |
|------|------|------|
| `ObservationStore` | **运行期自动** | 每次工具调用即落盘 observation + 原始产物 |
| `evidence_collector` | **任务结束主动** | 把散落证据打包成**可交付、可校验**的证据包 |

**证据包的价值**（不是"再存一遍"）：

1. **完整性校验**：每个文件 SHA-256 入清单 → 防篡改、防遗漏
2. **一次交付**：结对组拿到 tar.gz 即可离线复核
3. **缺什么说什么**：`gaps` 字段如实列出缺失项，不补造

---

## 2. 证据包结构

```
evidence-<runId>.tar.gz
└── evidence-<runId>/
    ├── MANIFEST.json      文件清单（path / bytes / sha256 / kind）
    ├── README.md          复核指引
    ├── audit.jsonl        该运行的审计事件（按 runId 过滤）
    ├── report.md          渗透报告（若已生成）
    ├── observations/*.json 结构化 Observation
    └── artifacts/*.txt    原始工具输出（HTTP 原文等）
```

### 关键设计决策

| 决策 | 理由 |
|------|------|
| **tar.gz**（非 zip） | Linux 通用、零额外依赖 |
| **按 runId 过滤 audit** | 避免把其他运行的事件混入，也避免泄露 |
| **MANIFEST 自身留在包内** | 校验清单必须与证据同包 |
| **缺失项写进 gaps** | 诚实性（R5 / 报告诚实性 10%） |
| **不修改原始证据** | 只复制 + 计算哈希 |

## 4. 发现的问题

### P1：Windows 上 tar 把 `C:` 当远程主机

**现象**：本机测试时报 `tar (child): Cannot connect to C: resolve failed`。

**原因**：Windows 自带 bsdtar 会解析 `host:path` 语法。

**修复**：先试 `tar --force-local`，失败回退（GNU tar 无此参数）。

> 容器内是 GNU tar，不受影响；此修复只为本地单测可跑。

### P2：报告中的 `TRACE_DEGRADED`

**现象**：本次报告显示 `观测完整度：TRACE_DEGRADED`。

**原因**：报告在任务进行中生成，此时 `run_end` 事件尚未写入，被判定为"trace 不完整"。

**性质**：**时序问题，不是缺陷**。若在任务结束后生成报告，应为 `TRACE_COMPLETE`。

**记录**：这是诚实的判定——报告生成时刻确实还没收到结束事件。

### P3：`evidence_collector` 不在 `PENTEST_TOOLS`

**现象**：收束拦截逻辑只针对 `PENTEST_TOOLS`，`evidence_collector` 不在其中。

**结果**：收束期可以正常调用——**这正是想要的行为**（Q1 决策：保留证据类工具）。

**记录**：`EVIDENCE_TOOLS` 白名单里已登记，语义明确。

## 8. 复现

```bash

docker compose exec -T agent sh -c 'export HOME=/tmp; cd /app/pi-pentest;
  PENTEST_ALLOWED_TARGETS=target,shiro PENTEST_RUN_ID=w3-evidence \
  NODE_OPTIONS="--require /work/proxy-setup.cjs" \
  pi --extension ./src/index.ts --no-extensions --no-session --print \
  "验证 target:8090 和 shiro:8080 的漏洞，然后生成报告并收集证据包"'

# 校验
cd deploy/runs/agent-work
sha256sum evidence-*.tar.gz
tar -xzf evidence-*.tar.gz -C /tmp && cd /tmp/evidence-* && cat MANIFEST.json
```
