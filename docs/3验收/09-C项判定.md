### C24 已补齐（原 FAIL）

`3验收/02` §1.2 要求"四态不动，`Finding` 增加正交维度 `verificationLevel`"，
且"`RISK_SURFACE` 不得写成'已利用'"。

补法：
- `Finding.verificationLevel: VerificationLevel | null`
- `CONFIRMED` → `RISK_SURFACE`；其余 → `null`（未确认的没有"强度"可言，
  给值等于暗示它也是一种风险等级）
- 报告表格加"验证强度"列，详情加一行；`NONE` 显示为 `—`
- `report.test.ts` 断言该字段，防止有人把探测命中改写成已利用

**赋值处仍无 `CALLBACK_RECEIVED` 分支**：类型已定义三值，但 `report.ts:192` 的赋值
只把 `CONFIRMED → RISK_SURFACE`，其余 → `null`。全量档已实现 `callback_watch`，
本轮场景未授予 callback 能力、未触发回连，所以没有真跑证据可证明该分支。
补法：在赋值处按 evidence 分流（有回连证据才给 `CALLBACK_RECEIVED`），并配一个真回连场景验证。
