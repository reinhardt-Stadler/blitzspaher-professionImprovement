## 2. 与本仓库契约的差异处理

1. **不回退既有修复**：参考分支的 `stepId`、`producesFacts` 豁免、`no_capability` 去重在本仓库已有，
   移植时逐段合并，未整文件覆盖。
2. **模式 id**：矩阵测试按本仓库 `TOOL_REGISTRY` 的 `http.probe` / `cve.verify`，不改注册表去迁就旧稿。
3. **arm=off**：`authorize_call` 现在把 `code=ARM_OFF_BASELINE` 随返回值给出，审计与返回值同源。
4. **账本 `none`**：`callback_watch` 不占两本账、不吃调用预算；闸门是 `callback` 能力授权。
5. **pi 消息类型**：本机 1.5.2 的 `SystemMessage.timestamp` 必填，`appendInjectionMessage` 补上，
   否则 `context_with_system` 注册在编译期直接失败。
6. **时间线扩展**：`TimelineStep` 增 `newFactKeys` / `target` 等评估层字段，
   重建时从 assessment 与审计参数同源填充，评分器不另写一套事实解析。

## 3.1 专项验收暴露的缺陷修复

`npm run verify:toolhost` 首跑 7/8：工程路径 `D:\Reinhardt's_ITmessage\...` 含单引号，
WSL 把 `execFile` 的 argv 重拼成 shell 命令时引号不闭合，报 `unexpected EOF`——
越界工具那条误判为"拦截层不可识别"，实际是命令根本没进容器。

修复：`toolhost/container.ts` 加 `wslShellQuote` / `isWslPrefix`，
仅 wsl 前缀对含 shell 元字符的参数整体加引号、内部 `'` 用 `'\''` 转义；
原生 docker/podman 不经 shell，不转义。复跑 **8/8 全过**。
