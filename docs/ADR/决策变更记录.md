# 决策变更记录（DCR）

> 定位：ADR 记录"决策及其理由"；本文件记录"决策被推翻/修订这件事"本身——保证任何技术决策可审计、可回溯。
> 规则：ADR 进入"已决定"后不得改写，变更一律走本文件开 DCR 单，并在被变更的 ADR 头部标 `→ 已被 DCR-NNN 修订/废弃`。
> 与 04-过程/需求变更记录.md 的区别：那边管"用户要什么变了"，这边管"我们决定怎么做变了"。

## 变更单模板

| 字段 | 说明 |
| --- | --- |
| DCR 编号 | DCR-001 递增 |
| 发起人 | 组内 / 对抗组 / 实验证据 |
| 变更原因 | 什么事实促使变更（实验数据、新候选出现、需求变更联动） |
| 影响决策 | ADR-NNN（可多选） |
| 旧决策 | 一句话 |
| 新决策 | 一句话 |
| 连带修改 | 需求 / 规格 / 验收 / 代码 / 文档中需要同步改动的清单 |
| 日期 | YYYY-MM-DD |
