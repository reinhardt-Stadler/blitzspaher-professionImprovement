**探测器安全原则**：三探测器均为**无损探测**（不发攻击载荷）：
- Fastjson：只触发 JSON 类型不匹配
- Shiro：只发非法 Base64，触发解密失败
- Struts2：OGNL 只做 `1+1` 算术并写响应头

## 背景

首版需要覆盖 R4/R5 至少两类漏洞的工具能力，且参数可被控制层结构化约束（SEC-PARAM-01）。

## 决策

暂定（待 OQ-04 时间盒 0.5 天实验确认）：

| 注册类别 | 工具 | 覆盖 |
| --- | --- | --- |
| scanner | nmap | 信息收集 / 服务识别 |
| web_probe | httpx 或 curl | Web 路径与指纹 |
| vulnerability_check | 单 CVE 验证脚本（首个目标：Fastjson 反序列化） | 漏洞验证 |
| evidence_collector | 待定型 | 证据留存 |

## 备选方案

- Metasploit 模块接入：能力全但参数面巨大，首版控制层约束成本高，淘汰至演进阶段再议。
- 更多 CVE 脚本：首版只承诺 1 个，防止范围蔓延（靶场同理：Vulhub 先起 2 个环境）。
