**必读的三个陷阱**（细则文档里标出，这里先记一笔）：

1. 上下文分层改 `details` 会**静默破坏** `pipeline.asObservation` 的判定 → 记账失效、`GAP_MISSING_OBSERVATION_REF`；
2. `TOOL_REGISTRY` **不能** import TypeBox，否则 `tools.ts` 失去零依赖属性（`security-control.ts` 先例作废）；
3. `report.ts` 硬编码 `tool === "cve_check"`，新增验证工具不改这里，报告静默丢结论。

## 3. 贵 / 便宜排序（决定开工顺序）

- **最贵**：B1 状态外置、C1 动态工具隔离、B3 审计四件套扩张；
- **中等**：A3 授权档位前置、C2 回连网络改造、C3 探测规格化；
- **最便宜且应先做**：A2 堵旁路、B6 表驱动注册、知识检索接线、D1 内核纯函数化。

**便宜四件恰是贵事的地基**：旁路不堵则动态工具等于开天窗；内核不纯函数化则状态外置与行为测试无从做起。
