## 5. 维护规矩

1. **单文件 ≤200 行。** 超了不是压缩，是**拆**——新建章节文件并在此表登记。
2. 新增文档必须在本索引 §2 登记，否则视为孤儿文档。
3. 状态标记：✅ 可开工　🟡 有前置　⏸ 卡实测　🔴 未调研。⏸/🔴 条目不写方案，只写"卡在哪、有哪几种分支"。
4. 每条 MUST 必须带验收映射，否则不许标 MUST（`1需求文档.md` §0 的规矩）。
5. 事实类陈述必须可复查（给文件:行），不允许"预计""应该"混进现状描述。
6. 原文三份长文档已保留为入口页（各 <40 行），指向本目录，**内容一字不丢地搬到这里**。
