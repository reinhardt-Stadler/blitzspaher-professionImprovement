## 2. 依赖与关键路径

```
RA-0.1 pi 实测 ──┬──> RA-0.2 漏斗白名单化 ──> RA-1.1 ──> RA-1.6 状态外置
                 └──> RA-0.3 事件规矩 / RA-0.4 文档修正 / RA-0.5 条目草案
RA-1.1 ──> RA-1.2 ~ RA-1.8（1.7/1.8 可与 1.2–1.6 并行）
RA-1 出口 ──┬──> RA-2（2.1/2.3 可先做）
            └──> RA-3 ──> RA-4 ──> RA-5
```

**关键路径**：`RA-0.1 → RA-0.2 → RA-1.1 → RA-1.6`。
RA-1.6 是整条链最重的一包——它不是"加个 save/load"，而是要求 RA-1.1 一开始就把状态设计成可重放。

## 3. 工作包编号与粒度

`RA-<阶段>.<序号>`。粒度标准：**一个包 = 一次可独立提交、可独立回退的改动**。
包内不再拆步骤，但每包必须回答三问：改哪些文件、接口长什么样、怎么证明它成了。

状态标记：✅ 可开工　🟡 有前置　⏸ 卡实测　🔴 未调研。
