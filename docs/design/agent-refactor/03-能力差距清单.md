## 2. 一句话诊断

现在是一套很强的"执法与取证系统"，套在通用 coding agent 的裸循环上。
缺的是**脑**（规划/记忆/知识）、**感知**（状态建模/结果判定）、**更长的手**（动态工具/回连）。
